# 🧨 砸个痛快 —— 发泄小游戏

> **万物皆可砸，砸得越响分越高。**
>
> 一款减压发泄小游戏：把房间里的任何东西砸碎砸烂，听"砰砰"清脆的碎裂声，一关一关通关。砸碎物品得积分，积分兑换虚拟礼品，攒出游戏里的级别与称号。**不用复杂，够发泄、有爽感。**

[🎮 立即试玩](https://kikifan-hub.github.io/-/index.html)（手机浏览器竖屏体验最佳）

## ✨ 游戏特色

| 特色 | 说明 |
|---|---|
| 🔨 万物可砸 | 玻璃杯、盘子、花瓶、电视机……拿起任何物品甩出去砸个粉碎 |
| 🔔 拟真碎裂音效 | 玻璃/陶瓷/木头/电子 4 种材质音效，WebAudio 纯代码合成，零外部素材 |
| 💥 爽感反馈 | 顿帧（砸中瞬间画面冻结）+ 震屏 + 连锁子弹时间 + 手机震动 |
| 🔥 连击连锁 | 碎片多米诺连锁砸碎更多物品，连击倍率 ×1.2 ~ ×5 |
| 🩹 裂纹阶段 | 耐久物品先出裂纹再碎裂，"砸不碎再来一下"的期待感 |
| 🏆 关卡星级 | 砸碎 60% 通关、80% 两星、100% 全清三星（积分 ×1.5 加成） |

## 🎮 怎么玩

- **电脑**：直接打开 [index.html](index.html)，或任意静态托管部署
- **手机**：浏览器打开上方试玩链接（触屏操作）
- **操作**：
  - 按住物品 → 拖拽甩出（有抛物线轨迹预览），大力砸
  - 停住后松手 → 轻放下落（是否碎裂由原碰撞规则决定，不是点击即碎）
  - 砸碎的碎片会连锁撞碎其他物品

## 🛠️ 技术说明

- **零依赖零构建**：单个 HTML 文件，双击即玩，可部署到任意静态托管（GitHub Pages / Vercel / 本地服务器）
- **程序绘制**：物品 = 多边形轮廓 + 几何细节（卡通扁平风），碎裂 = 按轮廓预分割碎片 + 2D 刚体物理
- **程序合成音效**：WebAudio（振荡器 + 噪声缓冲 + 滤波器 + 压缩器），每种音效配方详见设计方案
- **数据驱动**：关卡用 JSON 数据定义，加关只加数据不改代码
